What happens automatically?

Find root tracks → predict tissue labels → clean the mask → measure Periderm-labelled path length → report each root.

No polygons, tissue labels or manual transition points are needed. Each detected root is checked separately. V2 also runs the PAT segmentation model and cleanup, then sums the Periderm-labelled length along the detected root path. These mask-based estimates appear in the main table without requiring a confirmed transition or endpoint. Earlier transition-based measurements remain available for comparison. The withdrawn V2.1 experiment confused brightness changes with anatomy; it is available only as archived results. Endpoint and transition estimates still need biological validation. The detector weights are unchanged; no training occurs here. Possible blur, cut-off roots and unresolved touching roots can prevent measurement. Uncertain endpoints are flagged but do not suppress an otherwise calculable mask estimate. The preliminary blur check can miss poor images; it is not proof of image quality.
