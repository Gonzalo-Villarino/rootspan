MANUAL CONCEPT: IMAGE, POLYGON ANNOTATION AND PIXEL MASK
The original microscope image is a grid of pixels. Each pixel stores image
information such as brightness and colour. It tells us what the sample looks
like at that location. In our displayed microscopy image, both tissue classes
can look green; a display colour is not itself a tissue identity.

In Labelme, Gonzalo has already made the biological decisions: he drew closed
polygons and named each region Periderm or Endoderm. The annotation portion of
the JSON records the polygon point positions and tissue names. Our configuration
also embeds an image copy in the JSON; that does not make it a per-pixel label mask.

A pixel mask is a separate, matching grid with the same width and height as the
image used for annotation. At each corresponding position, it stores a class
label instead of the microscope pixel's colour or brightness. The labels are
usually stored as small whole numbers. For this learning example, the intended
mapping is 1 = Periderm, 2 = Endoderm, and 0 = unannotated. Unannotated does not
automatically mean confirmed background. Resolve overlaps deliberately before
conversion rather than silently depending on polygon drawing order.

Example: a green microscope pixel inside Gonzalo's Periderm polygon receives
the value 1 in the matching mask pixel. A different green microscope pixel inside
an Endoderm polygon receives 2. The original microscope image is unchanged.
Colours used to display the mask are a visual aid; the class numbers are the
information used in the label map.

The computer can fill the inside of each saved polygon with its class value.
Gonzalo does not redraw the roots or manually label every pixel. This converts
his existing manual segmentation decisions into a per-pixel representation;
it is not an AI prediction or a trained model. Later, a supervised segmentation
model can receive the microscope image as an input and use suitable checked masks
as the target labels, like an answer key. No training has happened yet.
